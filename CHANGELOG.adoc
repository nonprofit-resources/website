= Changelog

== 2026-08-16

* Catalog marks swap for the site theme (`html.dark`): white GitHub invertocat, white AWS smile, and cream-on-forest tiles for partner placeholders. Colorful vendor marks are unchanged. Header octocat follows the same white-on-dark treatment.
* Account links send signed-out visitors to the sign-in page, then back to `/account` after they authenticate.
* Compare adds a searchable picker so you can grow an n-column table without leaving the page. After the first offering, new columns stay in that category and listing type (programs vs apps).
* Footer “Ryan Johnson” points at ryanjohnson.dev.
* Primary nav only highlights the current section (Compare no longer stays selected on every page). Catalog “Absolutely free” is a checkbox row above the chips, not an orange-bordered chip.

== 2026-08-15

* OSS.Fund listed as a featured meta-directory; live OSS-friendly / nonprofit-tagged platforms imported from `oss-fund/directory` (CC BY 4.0) into a new **Open source** category and “For open-source projects” filter (`?oss=1`).
* Catalog pull API `GET /api/catalog`, outbound `catalog.updated` webhooks, inbound GitHub hook at `/api/webhooks/github`, and a scheduled `Sync OSS.Fund` workflow (OSS.Fund has no HTTP API).
* Regenerated `public/favicon.svg` from the org giving-hand logo (tab icon was still the old lettermark). Apple touch icon points at `logo-256.png`.

* Extracted `logo-only.svg` (hand + heart, no cream tile) plus PNG siblings at 512 and 256.
* Favicon keeps the cream tile but scales the mark up so it sits close to the edge (`pnpm logo:export`). The full `logo.svg` still uses the looser branding pad.
* Auth stays **Better Auth** (email/password + optional GitHub) with Drizzle `user` / `session` / `account` / `verification` tables created on first use.
* Offerings schema now models **programs** vs **platform apps** (Google for Nonprofits → Workspace, Ad Grants, YouTube, Maps; Microsoft → M365 + Azure credits). App search results use a stacked platform+app mark. Entity pages list child apps; apps live at `/services/<program>/<app>`.
* Compare tray + `/compare` sideways feature table. Operator notes wait on **human org verification** (`/account`, `/staff`, Turso tables `org_profiles` / `offering_reviews`).
