# Nonprofit Resources Website

SolidStart catalog for [nonprofit-resources.org](https://nonprofit-resources.org). See link:CHANGELOG.adoc[CHANGELOG] for what changed.

== Stack

* SolidStart + Tailwind + Kobalte (solid-ui style components)
* Turso (libSQL) + Drizzle + Better Auth
* Customer.io (news subscribe) + Resend (transactional)
* AsciiDoc content under `content/` (`news`, `blog`, `guides`)

== Develop

[source,bash]
----
pnpm install
pnpm logo:export
pnpm media:download
pnpm content:build
pnpm dev
----

Copy `.env.example` to `.env` and fill Turso / auth / mail keys when ready.
Local catalog works from seed data without Turso; auth, submissions, operator notes, and human verification need a database URL (`file:./data/local.db` locally, Turso `libsql://…` on Netlify).

Set `ADMIN_EMAILS` to the people who may open `/staff` and approve org verification.

== Catalog feed

`GET /api/catalog` is a public JSON dump (CORS on). Outbound webhooks and the OSS.Fund GitHub ingest live under `/api/webhooks`. See link:content/guides/keep-the-catalog-in-sync.adoc[Keep the catalog in sync]. Refresh the import with `pnpm catalog:sync-oss-fund`.

== Deploy

Netlify is a **blank / manual** site on the personal team (no GitHub org repo connection — avoids Netlify team pricing).

CI: `.github/workflows/deploy-netlify.yml` builds on GitHub Actions and runs `netlify deploy` with `NETLIFY_AUTH_TOKEN` + `NETLIFY_SITE_ID` secrets.

Primary domain: `nonprofit-resources.org` (`.com` redirects in `netlify.toml`).
