# Nonprofit Resources Website

SolidStart catalog for [nonprofit-resources.org](https://nonprofit-resources.org).

== Stack

* SolidStart + Tailwind + Kobalte (solid-ui style components)
* Turso (libSQL) + Drizzle + Better Auth
* Customer.io (news subscribe) + Resend (transactional)
* AsciiDoc content under `content/`

== Develop

[source,bash]
----
pnpm install
pnpm media:download
pnpm content:build
pnpm dev
----

Copy `.env.example` to `.env` and fill Turso / auth / mail keys when ready.
Local catalog works from seed data without Turso; auth and submissions need a database URL.

== Deploy

Netlify (`netlify.toml`). Primary domain: `nonprofit-resources.org` (`.com` redirects via infra).
